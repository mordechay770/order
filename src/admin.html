Логотип и название
Цвет оформления
Основной цвет применяется к заголовкам, кнопкам и акцентам по всему сайту заказов.
Контактная информация
Контакты показываются внизу главного экрана формы заказа. Оставьте поля пустыми, чтобы скрыть.
Объявления и баннеры
Баннеры показываются на главном экране. Опционально можно добавить кнопку-ссылку к каждому баннеру.
🔗 Кнопки на страницах
Кнопки-ссылки отображаются под объявлениями на выбранных страницах.
Используйте для WhatsApp, телефона, важных ссылок, записи на приём и т.д.
Типы заказов
Типы заказов — это карточки на главном экране (Шаббат, Праздник, и т.д.).
Чтобы скрыть тип — снимите галочку «Показывать».
Чтобы добавить новый — нажмите «Добавить тип».
Тексты интерфейса
Здесь можно изменить любой текст в форме заказа для каждого языка.
Способы оплаты
Включите нужные способы оплаты. Они будут показаны клиенту на шаге оплаты.
Оставьте пустым, если используете только QR или кассовый терминал.
Вебхуки Make.com
Инструкция: Вставьте URL вебхуков из Make.com. Все URL должны начинаться с https://hook.eu1.make.com/.

После сохранения — скопируйте значения в блок CONFIGURATION файла order-form.html.
⚠️ Безопасность вебхуков:
URL вебхуков видны в исходном коде страницы для клиентов.
Рекомендации:
1. В Make.com → Webhook настройки → включите «Restrict to specific IPs» или добавьте секретный заголовок (Header: X-Secret: your-token)
2. Добавьте в каждый сценарий проверку: если заголовок отсутствует → вернуть 403
3. Не размещайте admin.html на публичном URL — храните на закрытом поддомене или защитите паролем на уровне хостинга (Netlify Password, Nginx basic auth)
Оставьте оба поля пустыми, чтобы не менять пароль.

Добавьте периоды Йом Тов и других праздников, когда заказы закрыты.
Экспорт и инструкции
Как применить настройки ко всем пользователям:

Вариант А (рекомендуется): Настройте Сценарий 7 в Make.com. Нажмите «Сохранить» — настройки отправятся в Airtable и автоматически применятся для всех пользователей при загрузке формы.

Вариант Б (без Make.com): Скачайте JSON ниже, откройте order-form.html в текстовом редакторе и замените блок SITE_CONFIG и ORDER_TYPES вручную.
Инструкция по развёртыванию

Файлы системы:

  • order-form.html — форма заказа для клиентов
  • admin.html — эта панель управления

Make.com сценарии:

  • 5a — GET меню по типу заказа
  • 5b — POST приём нового заказа
  • 5c — GET список дат/слотов (опционально)
  • 6a — WhatsApp менеджеру при новом заказе
  • 6b — WhatsApp клиенту при подтверждении
  • 7 — GET настроек сайта (для синхронизации)
  • 7b — POST сохранение настроек (из этой панели)

Airtable таблицы:

  • סוגי מאכלים — блюда (меню)
  • הזמנות — заказы
  • שורות הזמנה — строки заказов
  • תאריכי הגשה — даты подачи (слоты)
  • הגדרות האתר — настройки сайта (key-value)
🏛 Залы
Залы отображаются на шаге «Выбор зала» в форме мероприятия.
Без вебхука 8a — показываются залы из этого списка (без проверки занятости).
С вебхуком 8a — Make.com проверяет таблицу «Заказы аирвентов» на пересечение дат и возвращает available: true/false для каждого зала.
🛎 Дополнительные услуги
Услуги отображаются на шаге «Доп. услуги». Для каждой позиции можно задать рекомендацию — она показывается клиенту под названием услуги.
🔗 Вебхуки мероприятий
Вставьте URL из Make.com. Если поле пустое — данные берутся из редактора выше (из localStorage).
