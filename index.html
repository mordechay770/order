Что изменилось

  • Типографика — Fraunces serif для заголовков даёт «premium food» ощущение, Roboto остаётся для UI.
  • Палитра — navy #1B3A6B + gold #C9A84C обогащены кремовым paper #FAF6EC и тёплыми gold-tint поверхностями.
  • Карточки — мягкие тени, hover lift, капсульные CTA, gold glow вместо плоских border-left акцентов.
  • Оплата — grid 2×2 карточек (наличные / Kaspi / ваучер / частичная) с активным состоянием, чек-маркером и плавным fade-in деталей.
  • Hero-блоки — тёмный navy gradient с золотым свечением, звёздчатый паттерн, крупный Fraunces заголовок с курсивным акцентом.
  • Функциональность — ВСЕ ID, onclick, JS, webhook-пути, localStorage ключи, i18n словари сохранены 1-в-1.
